報名前常問的事

我不會寫程式，跟得上嗎？

跟得上。這堂課不教寫程式，每一步都在現場帶著做，會打字和登入帳號就行。

我的公司只有我一個人，適合嗎？

適合。一個人什麼都要自己來，最需要先把重複的事交出去。

一天做得完嗎？

當天會做好 AI 營運長、裝好 AI 策略長，再從營收長、行銷長、財務長選一位現場做出來。另外兩位給你範本，回去照著做。

兩人同行怎麼報名？

報名表選「兩人同行」，填上同行者的稱呼和手機，兩位每人 NT$4,800。BNC 會員價不跟兩人同行優惠疊加。

一定要買 Grok Premium 嗎？

要。Grok Bot 包含在 Premium（US$30／月，未稅）、Super、Ultra 方案，Plus 不含。建議上課前先開通，當天就能直接做。

Mac 和 Windows 都可以嗎？

都可以，上課請帶筆電。

Bot 可以接 LINE 嗎？

可以串 LINE 官方帳號。這不是 Grok 官方內建的連接，要用 LINE 官方帳號的 API 另外設定。課堂上會示範，詳細做法寫在操作手冊。

公司資料放進去安全嗎？

每位學員都用自己的帳號。銀行帳密、身分證字號和員工薪資明細不要放進去。

AI 策略長之後會自動更新嗎？

你帶走的是上課當天的版本，不會自動更新。

BNC 會員價怎麼申請？

報名表勾選 BNC 會員，送出後會出現 NT$3,600 的付款按鈕。行政會核對會員身分，不符資格的話會全額退款，再請你用一般價報名。

怎麼付款？可以開公司發票嗎？

送出報名資料後直接刷卡付款。付款時可以選二聯或三聯式電子發票，公司請選三聯式並填統一編號，發票會寄到你的 Email。想用匯款，請用 LINE 跟行政說。

報名後不能來，可以退費嗎？

12/23（三）前取消全額退費，之後不退，但可以把名額轉讓給別人。
